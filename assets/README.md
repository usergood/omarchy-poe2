# Plugin icon

`poe2-icon.png` is the plugin's transparent gold waystone **II** emblem, generated
with the built-in image generation tool. It is an independent launcher mark,
not an official Path of Exile logo. QML loads it at the bar's icon size.

Final generation prompt:

> Use case: logo-brand. Asset type: transparent PNG desktop/bar plugin icon for an independent Path of Exile 2 launcher. Create one distinctive emblem: a bold angular waystone-shaped rune with a clearly cut Roman numeral II in its center, framed by two restrained pointed dark-fantasy metal wings. Style: clean premium game utility emblem, warm antique gold and ivory highlights, extremely simple strong silhouette, flat forms with only subtle bevel shading. Front view, centered square composition, tight balanced silhouette with modest transparent padding. Must read clearly at 20–24 pixels, thick shapes, strong contrast, minimal detail. Actual transparent background. No gamepad, no lettering besides the two vertical strokes, no official game logo reproduction, no scenery, no drop shadow outside the emblem, no watermark. Deliver a single finished icon, not a sheet or mockup.
